# Public API Relay Services

A growing reference list of publicly available API relay services. The information below was checked on **2026-09-03** and may change without notice.

## KKTOKEN (KKtoken AI)

- **Registration:** The public sign-up page asks for a username, password, and password confirmation. It also offers a “Continue with GitHub” option.
- **Free quota:** No reliable public documentation was found stating a specific free credit, dollar, token, request, or daily allowance.
- **Limits and expiration:** No publicly documented model availability, request/token rate limits, concurrency limits, credit expiration, rollover, renewal, or inactivity rules were found.
- **Link:** [Sign up for KKTOKEN](https://kktoken.cc/sign-up?aff=kcGZ)

## AgentRouter

- **Registration:** The registration page was protected by an access-verification slider when checked. The Terms state that users must meet the applicable age requirement, provide accurate registration information, and comply with applicable law.
- **Free quota:** Official documentation confirms that free quota is offered, but does not state a reliable numeric amount. Do not rely on third-party claims of specific referral or signup amounts.
- **Limits and credits:** API usage is metered collectively across supported agents. No numeric request, token, spending, or concurrency limit was publicly stated. API calls may be rejected when credits are exhausted. The Terms say purchased credits are valid for 365 days, but this should **not** be assumed to apply to promotional or free credits.
- **Important restrictions:** API keys must be kept private. Resale, redistribution, unauthorized third-party use, security circumvention, scraping outside normal API calls, interference, and content or activities that violate applicable law or model-provider terms are prohibited.
- **Public API endpoints:** The official documentation lists `https://co.agentrouter.org` for Anthropic-compatible access and `https://co.agentrouter.org/v1` for OpenAI-compatible access. Model availability may change.
- **Link:** [Register for AgentRouter](https://agentrouter.org/register?aff=gHJB)

## JustWorker API (site branding: JustDoWork / New API)

- **Registration:** The public page shows username and password-confirmation fields, plus a “Continue with GitHub” option. The exact account requirements may change.
- **Free quota:** No reliable official public documentation was found stating a numeric free credit, balance, daily/monthly allowance, or credit-expiration date. Do not assume the service is unlimited.
- **Limits and access:** The unauthenticated `/v1/models` endpoint returned HTTP 401, indicating that an API key or token is required. The public status information did not expose numeric request, token, concurrency, or account limits. Public documentation was not enabled when checked.
- **Model availability:** Third-party pages mention model identifiers, but these are not official quota or availability guarantees and may be outdated.
- **Link:** [Register for JustWorker API](https://api.justwoker.icu/register?aff=rTMp)

## General Safety Notes

- Review each provider’s current Terms of Service, privacy policy, pricing, and availability before use.
- Do not send passwords, API keys, private keys, seed phrases, personal information, confidential business data, or other sensitive content through an untrusted relay.
- Use separate credentials with the least privileges necessary, and rotate or revoke them if exposure is suspected.
- Service quality, availability, security, model access, and quotas are not guaranteed. Use these services at your own discretion and comply with all applicable laws and provider policies.
- Some links contain referral parameters. Listing a service does not constitute an endorsement or warranty.
