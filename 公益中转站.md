# Three Public API Relay Services

This file lists three publicly available API relay services for reference:

1. [KKTOKEN](https://kktoken.cc/sign-up?aff=kcGZ)
2. [AgentRouter](https://agentrouter.org/register?aff=gHJB)
3. [JustWorker API](https://api.justwoker.icu/register?aff=rTMp)

## Usage Notes

- Please review each service's terms of service, privacy policy, pricing, and availability before using it.
- Do not submit passwords, API keys, personal information, confidential business data, or other sensitive content unless you fully trust the service and understand its data-handling practices.
- Treat third-party relay services as untrusted intermediaries: use separate credentials, apply least-privilege permissions, and rotate or revoke credentials if necessary.
- Service quality, availability, and security are not guaranteed. Use these links at your own discretion and comply with all applicable laws and provider policies.
- The links above may contain referral parameters. This document does not constitute an endorsement or warranty of any listed service.
